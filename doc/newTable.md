# Utworzenie nowej tablicy

## Plik z tabelami

`drupal/web/modules/custom/rsvplist/rsvplist.install`

## Jak przeprocesować instalację

Aby zostały utworzone nowe tabele, należy odinstalować moduł i zaintalować ponownie.
Wówczas jest wywoływany plik intalacyjny *.install, w tym przypadku `rsvplist.install`.
